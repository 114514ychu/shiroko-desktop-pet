# 白子桌宠 1.0.0

Windows 10/11 x64 本地应用。安装后直接运行，无需另外安装 Node.js、Python 或 Electron。

四套服装（普通、骑行、泳装、黑子）、139 段原始动作、互动原录音与中文字幕可离线使用。点击人物闲聊；长按提起并拖动；右键按住旋转；滚轮缩放。泳装源模型没有专用提起动作，长按保留当前姿态并支持拖动和原声。

关闭主窗口后桌宠继续运行；完全退出请使用托盘菜单。

## DeepSeek 对话

打开应用设置，填入自己的服务地址、模型和 API Key，保存后测试连接。默认地址是 DeepSeek 的 chat/completions，模型 deepseek-chat，也支持兼容接口。消息发送给所配置服务，费用由该服务计费。密钥使用当前 Windows 用户的本机加密保存，切换服务域名需重新填写密钥。

手动打开的聊天框会持续保留，回复结束、语音播完、空闲或失去焦点都不会自动收起，可直接继续输入；点击关闭、收起或按 Esc 可手动关闭。点击人物和托起触发的原录音气泡仍按原来的播放结束与超时规则收起。

语音输入：点击“麦”或按 Alt+V，等待“正在听”后说话；本地识别组件可在说完后点击“完成”结束录音并识别。停顿后也会自动结束，单次最长 20 秒。“■”用于取消本次输入。文字填入草稿后可以编辑再发送，不会自动发送。首次加载中文识别模型可能需要十几秒，闲置后会释放；若使用 Windows 后备识别，则等待它自动结束。

## 聊天记录与续聊

控制台右上角点击“聊天记录”，可搜索历史消息、查看完整对话、重命名或删除记录；选中记录后点击“继续这段对话”恢复上下文和未发送草稿，也可点击“新建对话”开始独立聊天。桌宠聊天菜单中也有聊天记录入口。删除需要确认。

聊天记录自动保存在 %APPDATA%\ShirokoPet\chat\history，重启应用和覆盖升级后仍保留。普通、骑行和泳装共享白子会话，黑子使用独立会话；切换历史不会重新朗读旧消息。切换对话会停止上一段未完成的请求与语音，未完成消息可重试。

完整文字保留在本机；发给所配置聊天服务的上下文有长度限制。长对话会在后台偶尔调用同一聊天服务生成摘要，帮助延续较早内容，因此可能产生额外接口用量。摘要失败不影响原聊天记录。需要接着之前的话题时，请选择对应历史继续；需要跨对话保留的偏好，可使用下面的长期记忆。

## 智能助手

控制台右上角“智能助手”管理长期记忆、提醒、能力授权与陪伴设置。当前版本可读取本机时间、日期与时区，计算算式和日期差，检索本地历史，保存明确的记忆，以及创建和取消提醒。普通问题由 DeepSeek 判断是否调用工具，执行后再回答；兼容接口拒绝工具时会退回普通聊天。最多五轮模型请求、八次工具调用，工具请求可能增加接口用量。可手动关闭聊天框取消未完成的请求。

以下明确句式直接在本机处理，不需要先请求 DeepSeek：“现在几点？”“6*7”“记住：我喜欢骑车”“十分钟后提醒我喝水”。时间以电脑系统时间为准。日期差、较复杂的自然语言请求和历史检索需要配置支持工具调用的聊天服务。

长期记忆与聊天记录分别保存，换一段对话也能参考明确保存的记忆。只在用户说“记住”或在面板添加时保存，支持查看、编辑和确认删除。记忆及被工具检索到的历史片段会作为资料发送给你配置的聊天服务，不应在其中保存不愿发送的信息。此版本不会自动学习全部历史。

提醒先保存后确认，软件运行时到点显示系统通知；桌宠空闲时使用当前角色原有音色播报，不打断正在回复或播放的对话。日语播报提示提醒到点，具体事项显示中文。排队超过五分钟的语音不再补播；通知仍保留。关闭软件期间不会唤醒电脑或发送通知，下次启动将过期单次提醒标为“错过”；重复提醒跳到下次，不连续补发。通知能否弹出受 Windows 通知设置影响。

助手数据保存在 %APPDATA%\ShirokoPet\assistant\assistant.json，使用原子写入与备份。工具列表中可以随时关闭相应调用。新增能力和授权方式见下文。

## 新增实用功能（2026-10-24）

- 聊天输入框的“麦”或 Alt+V 开始一次中文离线识别，本地组件录音时点击“完成”结束并识别，“■”取消。文字填入草稿，可修改后发送；不会持续监听或自动发送。需要麦克风权限与正确的 Windows 默认输入设备；未安装本地模型时使用 Windows 中文识别。识别效果因环境而异，无法识别时可继续打字。
- “■”停止当前回复与语音，保留窗口；停止中的提问回到输入框，可修改重发。
- 提醒可选每天、工作日、每周；第一次时间仍要明确（工作日首次需选工作日）。支持延后十分钟与取消。聊天可直接说“每天早上八点提醒我喝水”“工作日下午三点提醒我休息”“每周一上午九点提醒我开会”。提醒不会唤醒已关闭的软件或睡眠电脑。
- “能力设置”可开启联网搜索与天气，默认关闭。支持 Bing RSS 搜索、Open-Meteo 天气和未来三天预报；回复应附来源及查询时间。城市可用中文或拼音，同名城市请补充信息。查询速度及可用性取决于网络和上游服务，不保证网页摘要的完整性。Bing RSS 需遵守其个人非商业使用条件。
- 选择授权文件夹后，可对话查找文件名、读取小文本（UTF-8 的 txt/md/csv/json/log/yaml，最大128KB，传给聊天最多12000字符）。查找限制为四层目录、3000项和40条结果，链接目录不遍历；撤销后不可继续读取。查询可能不覆盖目录中的所有文件。读到的内容可能随对话发给配置的服务。
- 自动查找并打开已安装软件，无需选择 exe 或逐个添加名称。直接说“打开微信”“打开QQ”“打开记事本”；明确的打开请求在本机处理，不需要先请求 DeepSeek。名称重复时列出候选，请再说“打开完整名称”选择。查找覆盖开始菜单的应用快捷方式和 Windows 应用注册信息，未注册的便携软件可能找不到；不会扫描整个硬盘。在“能力设置”中可关闭自动打开软件。文件夹仍单独授权，聊天时使用完整文件夹名称。没有任意命令执行或修改、删除文件的工具。
- 复制选中的文字后，“准备剪贴板总结草稿”将内容放进聊天输入框；检查后点击发送才调用服务。最多5500字，已有聊天时请先关闭再准备；不会后台监视剪贴板。
- “陪伴设置”可开启一次问候、15–240分钟休息提示、原音色播报及免打扰时段，默认关闭。不打断聊天，电脑闲置超过五分钟暂停提示，无额外模型请求。正式安装版可选开机启动；托盘右键可退出。

文件夹授权与助手设置保存在本机助手数据中；联网会将搜索词或城市发给相应服务。没有改动角色点击、托起、服装和原录音。

## 保留音色

互动原录音已内置。AI 聊天生成的新内容可使用可选本地语音组件：普通、骑行、泳装使用白子模型；黑子使用独立模型。

默认使用独立安装的 GSV-TTS-Lite。程序会自动查找桌宠旁、用户数据目录和安装盘根目录的 GSV-TTS-Lite 文件夹，找到后记住位置；设置里的旧路径失效时也会重新查找。勾选“为聊天回复合成声音”并保存。本机默认地址为 http://127.0.0.1:9881/synthesize。普通用户只需启动桌宠，无需打开训练环境或另开 9880。发送消息时开始加载模型，与 DeepSeek 回复并行；也可在应用设置点击“启动并准备语音”，等待显示音色准备好后再聊天。连续聊天复用同一进程，闲置五分钟后释放。退出桌宠也会释放语音进程。释放后的第一条回复需要重新加载模型。AI 回复用日语口播、中文字幕，合成失败仍保留文字。

白子与黑子的原有 GPT/SoVITS 权重和参考录音继续使用，无需重训。一次只加载当前音色，切换服装时替换模型。默认日语口播、中文字幕；明确要求“用英语回答”“朗读英文”或“翻译成英文”时，保留英文口播，不再自动转成日语。英文与日语夹英文共用 GSV 自带的英文词典与音素前端，不需要另装大型模型。日语聊天不加载中文 BERT 辅助模型；独立 GSV 试听页的中文功能不变。麦克风识别只在点击“麦”时加载，闲置一分钟后释放，不持续监听。

聊天采用流式接收和分句合成：已生成的句子提前准备，先播放第一句，播放期间继续合成后续句子；中文字逐步显示。没有独立显卡也能使用这项优化。它缩短听到首句的等待，不会消除联网生成回复或首次模型加载的时间。

GSV 需要独立安装的运行环境、依赖和模型。优先 GPU；GPU 初始化、进程崩溃或明确 CUDA 合成错误时自动换成 CPU，并重试当前请求一次。CPU 回退在本轮服务运行期间保持，闲置释放或手动停止后重新优先尝试 GPU。参数错误与用户取消不会触发回退。

旧 ShirokoVoice .petpkg 仍可通过“安装兼容组件包”安装，并使用原 GPT-SoVITS 后端；与 GSV 共用旧权重。新语音服务与旧语音服务不应同时手动启动。

组件可另放其他磁盘。搬动已安装组件后，在设置中重新选择组件目录并保存。组件无需使用原电脑的 E 盘路径或已有 Python。

## 数据和升级

个人设置、日志和本机加密密钥放在 %APPDATA%\ShirokoPet。截图位于其 students\sunaookami-shiroko\captures 中。应用设置提供打开数据目录和导入旧版外观设置入口；导入后退出再打开生效。

使用后续版本安装器覆盖升级，卸载默认保留个人数据。当前没有自动更新服务器。语音组件由用户选定目录存放，卸载主程序不会删除该目录。

状态跟随默认关闭；需要时配置本机 Harness 路径，打开应用和学生面板中的跟随开关。
