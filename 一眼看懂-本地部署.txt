白子桌宠｜给普通用户的安装说明

一、先下载

如果下载的是完整便携版，请把 part01 到 part07 七个 ZIP 全部下载。
只下载一个包，软件可能打不开或缺少人物、声音。

二、解压

1. 新建一个文件夹，例如：D:\白子桌宠
2. 把七个 ZIP 依次解压到同一个位置。
3. 最后应该看到一个 ShirokoPet 文件夹。
4. 不要只复制里面的 EXE，也不要在压缩包里直接运行。

三、启动

打开：

ShirokoPet\启动白子桌宠.cmd

也可以双击：

ShirokoPet\ShirokoPet.exe

第一次启动和第一次合成声音会比较慢，请等待一会儿。

四、设置聊天

打开“应用设置”，填写你自己的 DeepSeek API Key，保存后点击测试连接。

没有 DeepSeek Key，也可以使用人物显示、换装、拖动和原声互动；只是不能进行 AI 对话。

五、设置声音

在设置里勾选：

为聊天回复合成声音

软件会自动使用白子音色。普通、骑行、泳装使用白子声音，黑子使用黑子声音。

不用手动打开 GPT-SoVITS，也不用手动启动 9880 或 9881。

六、使用麦克风

点击聊天框里的“麦”，看到“正在听”后说话，说完点击“完成”。
识别出的文字会放进输入框，检查后再发送。

七、没有声音怎么办

1. 确认“为聊天回复合成声音”已勾选。
2. 确认 GSV-TTS-Lite 文件夹完整，并且和 ShirokoPet 在同一套文件中。
3. 在设置里点击“启动并准备语音”。
4. 第一次加载可能需要几十秒。

八、重要提醒

每个人都要填写自己的 API Key，不要使用别人发来的 Key。
不要把 Data 文件夹上传或发给别人，里面可能有聊天记录和加密配置。
软件需要 Windows 10/11 64 位。
