文字总结

先选中文字并复制，再点击准备草稿。确认后发送才调用聊天接口。

主动问候和休息提示仅在桌宠空闲时出现，不打断聊天。无需调用模型，也不持续监听麦克风。相同的静音起止小时表示全天可提示。

麦克风按钮或 Alt+V 开始一次离线中文识别，看到“正在听”再说话；说完点“完成”识别，■ 可取消。文字填入输入框后可修改。首次加载本地模型可能需要十几秒；未安装本地模型时使用 Windows 中文语音组件。托盘右键可退出软件。
